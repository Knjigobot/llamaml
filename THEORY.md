## 1. Computation Graphs as Arrows in Free Monoidal Categories

Let $\mathbf{Graph}$ be the free strict monoidal category generated by the tensor primitive operations:
- Objects: Tensor shapes $A, B \in \mathbb{N}^4$.
- Generating Arrows: $\text{mul\_mat} : (K, M) \otimes (K, N) \to (M, N)$, $\text{rms\_norm} : D \otimes D \to D$, $\text{flash\_attn} : Q \otimes K \otimes V \to O$.

A computation DAG is an arrow $f : X \to Y$ in $\mathbf{Graph}$.

### Theorem 1 (Operator Fusion Homotopy)
Let $f = \text{silu} \circ \text{mul\_mat}(W)$ and $g = \text{fused\_mul\_mat\_silu}(W)$. Then $f \simeq g$ along the directed 1-simplex $\Delta^1$.
Mechanized in `formal/rzk/LlamamlHomotopy.rzk`:
```rzk

  (ForwardPass : Node -> U)
  (FusedForward : Node -> U)

```

## 2. FlashAttention-2 Online Softmax Invariance

Standard attention requires materializing the full attention matrix $S = Q K^T \in \mathbb{R}^{N \times N}$.
FlashAttention-2 computes the output $O \in \mathbb{R}^{N \times d}$ using running state $(m_i, \ell_i, O_i)$ across blocks:

$$m^{(k)} = \max(m^{(k-1)}, \tilde{m}^{(k)})$$
$$\ell^{(k)} = e^{m^{(k-1)} - m^{(k)}} \ell^{(k-1)} + e^{\tilde{m}^{(k)} - m^{(k)}} \tilde{\ell}^{(k)}$$
$$O^{(k)} = \text{diag}\left(e^{m^{(k-1)} - m^{(k)}}\right) O^{(k-1)} + e^{\tilde{m}^{(k)} - m^{(k)}} \tilde{P}^{(k)} V^{(k)}$$

### Theorem 2 (Online Softmax Invariance)
$$\lim_{k \to K} \frac{O^{(k)}}{\ell^{(k)}} = \text{softmax}\left(\frac{Q K^T}{\sqrt{d}}\right) V$$

## 3. Cordis Spatiotemporal Invariant & Speculative Decoding

In speculative decoding, a lightweight draft model generates $K$ tokens in state $S_0 \to S_K$, verified in parallel by the target model:

```
        State S_0
         /     \
   Draft  /       \ Target Verify
       v           v
    State S_K ===> State S_M  (M <= K)
        Rollback Discarded (K - M)
```

By the 2-Simplex Commutativity Law:
$$\text{Verify} \circ \text{Draft} \simeq \text{DirectTarget}$$
Any rejected draft tokens are undone via Cordis revertible LIFO effects in $O(1)$ time by adjusting the KV cache pointer $n_{\text{past}}$.
